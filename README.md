## Featured project

### Arquivo Sombrio

Web catalog of horror movies and series, suspense and slasher. The app searches for titles in the TVmaze API and lets you save your favorites in a personal file, saved in a database to continue there when the page is reopened.

- Website: https://arthur-bradley-barroca.github.io/bootcamp2-app/
- Code: https://github.com/arthur-bradley-baroque/bootcamp2-app
- Docker image: https://hub.docker.com/u/arthurbarroca
