## Projeto em destaque

### Arquivo Sombrio

Catálogo web de filmes e séries de terror, suspense e slasher. O app busca os títulos na API do TVmaze e deixa você guardar seus favoritos em um arquivo pessoal, salvo em banco de dados para continuar lá quando a página é reaberta.

- Site: https://arthur-bradley-barroca.github.io/bootcamp2-app/
- Código: https://github.com/arthur-bradley-barroca/bootcamp2-app
- Imagem Docker: https://hub.docker.com/u/arthurbarroca

Feito com HTML, CSS, JavaScript, Supabase e Docker, durante um bootcamp.
